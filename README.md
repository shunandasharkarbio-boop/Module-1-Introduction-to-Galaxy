# 🧬 Module 1: Introduction to Galaxy

## 📖 Overview

This project provides a beginner-friendly introduction to the **Galaxy** platform, an open-source, web-based environment for reproducible bioinformatics research. Through hands-on exercises, it explores the Galaxy interface, workflow execution, dataset management, and the fundamentals of sequencing data analysis.

Designed for newcomers to bioinformatics, this module builds the foundation for performing computational analyses without requiring programming experience.

---

## 🎯 Objectives

- Become familiar with the Galaxy user interface
- Learn how to upload and manage datasets
- Execute bioinformatics workflows
- Explore basic Next-Generation Sequencing (NGS) analysis
- Understand the principles of reproducible research
